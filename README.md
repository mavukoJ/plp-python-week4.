# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python assignment for the PLP programming course.

- **welcome.py:** Defines a `welcome()` function that returns a greeting for a given name.
- **toolbox.py:** Defines three functions: `double()`, `is_pass()`, and `greet()`.

The hardest function for me to write was `greet()` because I needed to understand how to use a default parameter. I learned that the function uses `"Hello"` when no greeting is provided, but I can also pass a different greeting, such as `"Habari"`.
